# Учебные материалы ДГТУ — 2026/2027

Одностраничное веб-приложение (SPA) для просмотра учебных материалов
**2026–2027 учебный год, профиль Уголовно-правовой, 1 курс, 40.03.01 Юриспруденция (ЮЗЮS) — бакалавр (сокращённая)**.

## Особенности

- 📂 **Дерево папок** из `materials/` строится автоматически через `import.meta.glob` (Vite) —
  поддержка любой глубины вложенности, аккордеон дисциплин, иконки по типу файла.
- 👀 **Просмотр прямо в браузере** (без скачивания):
  - PDF — pdf.js (`pdfjs-dist`), рендер всех страниц на canvas;
  - DOCX — mammoth.js (режим чтения, включая картинки);
  - PPTX — извлечение текста слайдов через собственный Web Worker (ZIP + `DecompressionStream`);
  - XLSX/XLS — SheetJS (`xlsx`) с вкладками листов;
  - изображения — лайтбокс; текст/аудио/видео — встроенные просмотрщики;
  - неподдерживаемые форматы — сообщение + кнопка «Скачать».
- 🗜 **ZIP собираются на лету в браузере** (JSZip + FileSaver).
  Готовые архивы в репозитории **не хранятся** — папка `materials/архивы/` удалена из Git
  и добавлена в `.gitignore`.
  - «Скачать предмет (.zip)» — вся дисциплина;
  - «Скачать выбранное» — только отмеченные чекбоксами файлы;
  - «Скачать всё» — все дисциплины одним архивом (осторожно, ~250 МБ);
  - прогресс-бар сборки при каждом скачивании.
- 🔍 Поиск по названиям файлов и папок, 🍞 хлебные крошки, 🌙 тёмная тема,
  💾 запоминание последнего открытого файла (localStorage).
- 📱 Адаптивность от 320 px: на мобильных дерево сворачивается в выдвижную панель (☰).


```bash
npm run build      # результат в dist/
npm run preview    # локальный просмотр сборки
```

## Деплой на Vercel

1. Залейте репозиторий на GitHub (папка `materials/архивы/` исключена через `.gitignore`).
2. На [vercel.com](https://vercel.com) → **New Project** → импортируйте репозиторий.
3. Фреймворк определится автоматически (Vite). Параметры:
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. **Deploy**. Для повторных деплоев достаточно `git push` (при подключённом репозитории)
   или CLI: `npx vercel --prod`.

> ⚠️ ВНИМАНИЕ: в репозитории не должно быть бинарных ZIP-архивов — приложение собирает их само.
> Если они появятся снова, выполните:
> ```bash
> git rm -r --cached "materials/архивы"
> git commit -m "Убрал ZIP-архивы: приложение собирает их на лету"
> git push
> ```
